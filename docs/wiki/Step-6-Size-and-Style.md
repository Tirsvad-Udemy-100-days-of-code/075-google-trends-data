# Step 6: Size and style

Make the chart readable: figure size 14 by 8, `dpi=120`, font size 14 for labels and ticks, x ticks rotated 45 degrees, a title, thicker lines (`linewidth=3`) and axis limits (`set_ylim`, `set_xlim`). `plt.show()` displays the chart explicitly.

![Step 6: Size and style](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/075-google-trends-data/raw/branch/main/docs/images/tesla-3-styled.png)

**What you gain:** Fine-tuning size, resolution, fonts, rotation and limits so a chart stays sharp and easy to read.
