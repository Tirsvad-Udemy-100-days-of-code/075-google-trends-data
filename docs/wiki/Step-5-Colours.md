# Step 5: Colours

Colour the lines and the axis labels so each label belongs to its line: a HEX code (`#E6232E`) for the stock price and a named colour (`skyblue`) for the search trend.

![Step 5: Colours](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/075-google-trends-data/raw/branch/main/docs/images/tesla-2-colours.png)

**What you gain:** Matplotlib accepts both named colours and HEX codes, and colour helps the reader match an axis to its line.
